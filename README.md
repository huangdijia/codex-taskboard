# Codex TaskBoard

用看板整理你的 Codex 聊天，方便查看哪些工作正在进行、哪些结果需要检查、哪些已经验收。

从 Codex 侧栏打开看板，按项目切换聊天，点击聊天标题即可回到对应的聊天继续处理。

## 主要功能

- **按项目查看**：切换项目，也可以搜索项目名称或路径。
- **快速找到聊天**：搜索聊天标题，直接打开对应聊天。
- **手动验收**：将检查过的结果标记为完成，需要继续处理时重新打开。
- **拖动卡片**：在待验收和已完成之间移动卡片。
- **明暗主题**：默认跟随 Codex，也可以在看板内手动切换。

## 三种状态

| 状态 | 含义 |
| --- | --- |
| InProgress · 进行中 | 看板观察到聊天有新的执行进展。 |
| Review · 待验收 | 本轮处理已结束，或状态需要确认，等待你检查结果。 |
| Done · 已完成 | 你已检查结果，并在看板中标记完成。 |

看板状态根据聊天活动更新，可能存在延迟；需要确认进度时，请打开原聊天查看。完成标记由你决定，只用于看板管理，不改变原聊天内容或归档状态。

向已完成的聊天发送新消息后，它会重新进入处理流程。

## 安装 prompt

需要 Codex 桌面客户端和 Node.js 26 或更新版本。复制以下 prompt 给 Codex，让它协助安装：

```text
请帮我安装 Codex TaskBoard 插件：
https://github.com/huangdijia/codex-taskboard

优先使用本地已有仓库，没有时克隆到合适的工作目录，并保留已有未提交改动。
检查安装所需环境，使用仓库提供的构建脚本和插件配置完成构建、测试与安装。
安装后，协助我从 Codex 侧栏打开看板，确认项目切换、聊天搜索和三列显示正常。聊天验收由我手动操作。
最后告诉我安装结果，以及需要我执行的重载或重启步骤；尚未验证的部分请明确说明。
```

## 卸载 prompt

不再需要看板时，复制以下 prompt 给 Codex：

```text
请帮我卸载 Codex TaskBoard 插件（codex-taskboard）。

检查当前安装状态，使用 Codex 提供的卸载方式移除插件；如果已经卸载，请确认现状。
若存在仅供该插件使用的安装来源，也一并移除。
保留我的 Codex 聊天、项目文件、本地仓库和看板验收记录。
最后确认插件已不在已安装列表中，并告诉我需要执行的重载或重启步骤；尚未验证的部分请明确说明。
```

## 日常使用

1. 从 Codex 侧栏打开 **Codex TaskBoard**。
2. 选择项目，或通过搜索找到聊天。
3. 点击聊天标题，查看结果并继续沟通。
4. 确认结果后，将卡片从 **Review** 拖到 **Done**；需要再次处理时，从 **Done** 拖回 **Review**。

聚焦卡片后，也可以用 `Alt+→` 验收、`Alt+←` 重新打开。进行中的卡片不能手动移动；提示数据过期时，请先刷新再操作。

默认隐藏归档聊天、子 Agent 和自动化聊天。窄窗口可以横向滚动查看三列。

## 常见问题

- **安装后找不到看板或无法打开**：重载客户端的插件配置，必要时重启 Codex。
- **首次加载较慢**：聊天较多时需要等待，界面会显示读取提示。
- **提示读取失败或数据过期**：先刷新看板，待数据恢复后再验收。
- **重新打开后主题恢复了**：手动切换只影响当前看板页面，重新打开会恢复跟随 Codex。
